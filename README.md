# Lane Damage Classification & Segmentation

차선 훼손을 **이미지 단위로 등급 분류**하는 것과, **픽셀 단위로 손상 위치까지 짚어내는 것** — 두 접근을 같은 데이터 계열에서 비교한 프로젝트입니다.

---

## 프로젝트 개요

도로 위 차선은 안전 운전의 기준선입니다. 하지만 실제 주행 환경에서는 대형 차량의 압력, 날씨 변화, 제설제 같은 화학적 요인 때문에 차선이 쉽게 훼손되고, 이는 야간·우천 시 시야 확보를 어렵게 해 사고 위험을 높입니다. 기존에는 고가의 휘도 측정 장비로 차선을 측정했지만, 데이터 수집·비용 문제로 한계가 있었습니다.

이 프로젝트는 **차량 내부 카메라 영상 + 딥러닝만으로 차선 훼손을 탐지**할 수 있는지 두 단계로 탐구했습니다.

1. **분류(Classification)**: 차선 이미지를 훼손 등급(A~D)으로 분류 (CNN Baseline → ResNet18)
2. **세그멘테이션(Segmentation)**: 같은 계열의 데이터에 픽셀 단위 손상 라벨을 추가로 확보해, 이미지 어디가 훼손됐는지 마스크로 예측 (U-Net)

등급만 아는 것보다 **훼손 위치와 면적까지 아는 것**이 실제 보수 우선순위 판단에 더 유용하다는 문제의식에서 세그멘테이션을 확장했습니다.

## Part 1. 이미지 단위 분류 (Classification)

### 데이터셋

| 클래스 | 설명 | 이미지 수 |
|--------|----------------------|---------|
| A | 정상 차선 (No damage) | 220 |
| B | 경미한 손상 (Minor damage) | 102 |
| C | 중간 손상 (Moderate damage) | 94 |
| D | 심각 손상 (Severe damage) | 13 |

총 **429장**. **문제점**: 클래스 불균형이 심각 → 특히 D 클래스(훼손 심각)가 13장뿐이라 학습이 어려움.

![Sample Images from Each Class](assets/classification/class_samples.png)

### 전처리 & 데이터 증강
- Resize 128×128, 정규화(평균 0.5, 표준편차 0.5)
- 학습 데이터에 한해 Random Horizontal Flip / Random Rotation(±10°) / Color Jitter 적용
- 단순 증강만으로는 클래스 D 부족 문제가 해결되지 않음을 확인 → 데이터 확보 자체가 더 중요하다는 결론

### 모델 및 결과

|---|---|---:|

| ResNet18 | Residual Block, scratch 학습(전이학습 없음) | 95.65% |

## Part 2. 픽셀 단위 손상 세그멘테이션 (Segmentation)

분류만으로는 "이 차선이 C등급이다"까지는 알아도 **정확히 어느 부분이 훼손됐는지**는 알 수 없습니다. 이후 확보한 데이터에는 차선 영역 폴리곤뿐 아니라 그 안의 **개별 손상 부위 폴리곤**(LabelMe 형식)이 함께 라벨링되어 있어, 이를 이용해 픽셀 단위 이진 세그멘테이션(damage / not-damage) 모델을 학습했습니다.

### 데이터셋

| 클래스 | 설명 | 이미지 수 | 손상 폴리곤 수 |
|---|---|---:|---:|
| A | 정상 (손상 라벨 없음) | 250 | 0 |
| C | 중간 손상 | 84 | - |
| F | 심각 손상 | 42 | - |

총 **376장**, 손상 인스턴스 폴리곤 **740개**(C+F 이미지에만 존재). A클래스는 전부 배경뿐인 마스크로, 모델이 "손상 없음"을 정확히 배우는 데 사용됩니다.

클래스별 8:1:1로 층화 분할했습니다.

| Split | 전체 | A | C | F |
|---|---:|---:|---:|---:|
| Train | 302 | 200 | 68 | 34 |
| Val | 37 | 25 | 8 | 4 |
| Test | 37 | 25 | 8 | 4 |

### 모델: U-Net (4-level, from scratch)

256×256 입력, 인코더-디코더 각 4단, 채널 32→64→128→256→512(bottleneck). 손상 클래스가 이미지 내 소수 픽셀이라 `CrossEntropyLoss(weight=[1.0, 5.0])`로 손상 클래스에 가중치를 줬습니다. Random Flip/Rotation/ColorJitter 증강, Adam + Cosine 스케줄, 60 epoch.

### 결과 (test set, n=37, 픽셀 단위)

| Precision | Recall | F1-Score | IoU |
|---:|---:|---:|---:|
| 0.560 | 0.912 | 0.694 | 0.531 |

Recall이 Precision보다 훨씬 높은 건 손상 클래스에 준 가중치(5.0)의 직접적인 결과입니다 — "놓치는 것보다 과탐지가 낫다"는 방향으로 일부러 편향시켰습니다. 작은 데이터셋(학습 302장)에서 사전학습 없이 처음부터 학습한 것치고는 합리적인 수준입니다.

### Original / Ground Truth / Prediction 비교

![U-Net GT vs Prediction](assets/segmentation/unet_gt_compare.png)

미세한 균열은 GT와 유사하게 잡아내지만, 일부 사례(3번째 행)에서는 실제보다 넓게 칠하는 과탐지 경향이 보입니다 — 위 Precision 0.56 수치와 일치하는 정직한 결과입니다. 마지막 행(A클래스, 정상 차선)에서는 예측도 정확히 아무것도 표시하지 않아, 모델이 "손상 없음"을 잘 배웠음을 보여줍니다.

## 활용 방안: 이 모델로 무엇을 하려는가

세그멘테이션 마스크를 만드는 것 자체가 목적이 아니라, **"이 차선을 얼마나 급하게 보수해야 하는가"를 계산하는 입력**으로 쓰는 것이 목표입니다.

1. 차량 블랙박스/CCTV 영상에서 주기적으로 차선 구간 crop을 추출
2. U-Net으로 각 crop의 손상 마스크를 예측 → `손상 픽셀 수 / 차선 전체 픽셀 수`를 "훼손도 점수"로 환산
3. GPS·구간 정보와 함께 누적해 도로 구간별 훼손도 지도를 생성
4. 훼손도 점수가 높은 구간부터 우선순위를 매겨 보수 일정에 반영

프로젝트 개요에서 언급한 "고가의 휘도 측정 장비" 없이도, 이미 다니는 차량의 카메라 영상만으로 **1차 스크리닝**을 자동화해서 사람이 전수 순찰해야 할 구간을 줄이는 것이 실질적인 활용 시나리오입니다. 심각도가 애매한 구간만 사람이 최종 확인하는 식의 반자동 워크플로우를 그립니다.

**다만 아직 실제 배포 단계는 아닙니다.** 지금은 "가능성 검증(proof of concept)" 단계이고, 실제 도로 데이터에서의 일반화, 실시간 처리 속도, 오탐이 유지보수 예산 낭비로 이어질 위험 등을 검증해야 다음 단계로 넘어갈 수 있습니다. 아래 "향후 개선 방향"의 사전학습 인코더 적용과 데이터 확충이 그 검증의 첫걸음입니다.

## 분류 vs 세그멘테이션, 언제 뭘 써야 할까

- **등급만 빠르게 알고 싶다면 분류**: 입력 하나당 라벨 하나만 있으면 되고, 라벨링 비용이 낮습니다(전체/부분 구분 없이 등급만 매기면 됨).
- **보수 우선순위·정확한 위치가 필요하다면 세그멘테이션**: 라벨링 비용은 훨씬 높지만(폴리곤 단위), 같은 차선 내에서도 "어디가" 심한지 알 수 있어 실제 보수 작업 계획에 더 직접적으로 연결됩니다.
- 이 프로젝트에서는 두 데이터셋의 클래스 체계도 다릅니다(분류: A/B/C/D 4단계, 세그멘테이션: A/C/F 3단계) — 동일한 촬영 소스에서 라벨링 방식만 바뀐 것이라 완전히 동일한 이미지 집합은 아닙니다.

## 느낀점 & 한계

- 작은 데이터셋에서도 CNN만으로 90%대 정확도 확보 가능했지만, 클래스 불균형(D=13장)은 증강만으로 해결되지 않음 → 데이터 확보 자체의 중요성을 체감
- 세그멘테이션은 라벨링 비용이 훨씬 크지만, "어디가 훼손됐는지"까지 답할 수 있어 실용성이 더 높음
- 세그멘테이션 데이터가 376장으로 여전히 작아 사전학습 백본을 붙이면(예: ResNet 인코더 U-Net) 추가 개선 여지가 있음
- 분류·세그멘테이션 데이터가 동일한 이미지 집합이 아니라, 두 모델의 성능을 직접 비교하기보다는 "같은 문제에 대한 서로 다른 접근"으로 해석하는 것이 정확함

## 앞으로의 개선 방향

- **사전학습 인코더 적용**: ResNet/EfficientNet을 U-Net 인코더로 사용해 작은 데이터셋에서의 일반화 향상
- **분류·세그멘테이션 데이터 통합**: 동일 이미지 집합에 두 라벨을 모두 붙여 직접 비교 가능하게 재구축
- **데이터 확충**: 다양한 도로 상황(비, 야간, 도심/고속도로) 데이터 확보
- **Synthetic Data**: GAN을 활용해 훼손 차선 이미지 합성, 특히 소수 클래스 보강
